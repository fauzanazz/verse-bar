What it does

Built for people who want the lyric without leaving their work.

♪

Live in the menu bar

The active lyric line sits in the macOS menu bar — lyric on the left, icon on the right, updating in real time.

✦

Glassmorphic popover

Click the icon for a scrolling lyric view with playback controls, sync offset, and a tap-to-seek timeline.

⌨

Touch Bar with controls

Open the popover and the MacBook Pro Touch Bar fills with the lyric plus tappable previous / play-pause / next buttons. Pin the popover to keep it on screen — and the Touch Bar — while you work in another app.

⚡

Browser-agnostic

Reads the macOS Now Playing system, so it tracks whatever's playing in Safari, Chrome, Arc, Dia, Brave, Vivaldi, Edge — anything with Media Session — plus the YTMDesktop companion server on port 9863.

⌁

LRCLIB-powered

Synced lyrics fetched from the open LRCLIB database, cached locally for instant load on repeat plays.

⌬

Tap to seek

Click any lyric line in the popover to jump the player to that moment — no manual scrubbing.

◐

Music Island under the notch

A Dynamic-Island-style pill docks under the MacBook notch with the live lyric. Hover to expand — it reveals the track info and tappable previous / play-pause / next controls.

✓

Guided first-run setup

A built-in setup window walks you through install location, Automation, and Notification permissions — with deep-links straight into the right System Settings pane.

◉

Album art

Cover artwork is pulled straight from the Now Playing source and rendered next to the title in the popover and the expanded Music Island. Falls back to a clean placeholder when the source omits it.

あ

Romanized lyrics

Korean (Hangul), Japanese (Hiragana / Katakana / Kanji), and Chinese (Han) lines are transliterated to Latin and shown under the original — also in the menu bar, Touch Bar, and Music Island so you can read along.

Install in 5 steps

Drag the app, grant permission, press play.

Download the .dmg

Grab PlayerStudio-vX.Y.Z.dmg from the releases page and double-click it.

Drag to Applications

In the mounted disk image, drag Player Studio onto the Applications shortcut. Done — that's the whole install.

Bypass Gatekeeper (one time)

Player Studio is ad-hoc signed but not notarized, so macOS will show "Player Studio was blocked to protect your Mac." Run this in Terminal to clear it for good:

xattr -dr com.apple.quarantine "/Applications/Player Studio.app"

Prefer the GUI? Open the app once, then go to System Settings → Privacy & Security and press Open Anyway. Either path is one-time only.

First launch & permissions

A built-in Setup Guide opens automatically and walks you through Automation and Notification permissions — one tap each, with deep-links to System Settings if anything was denied.

Play something

Open music.youtube.com, hit play, and the lyric appears in the menu bar within ~1.5s.

Or build from source

Single Swift build script. Needs Xcode Command Line Tools.

git clone https://github.com/fauzanazz/verse-bar.git
cd verse-bar
./build.sh
open "Player Studio.app"
